# 玉龍山弘憲寺延命院

正式URL：https://gyokuryuzanenmeiin.com/

東京都台東区元浅草の真言宗智山派寺院「玉龍山弘憲寺延命院」の公式案内サイトです。mainブランチのルートからGitHub Pagesで公開します。

## 主なファイル

- index.html：寺院紹介、由緒・歴史、境内、ご参拝、御朱印、交通案内、お問い合わせ
- styles.css：デザイン・スマートフォン対応
- assets/photos/：境内・本堂・御本尊の写真
- sitemap.xml / robots.txt：ページと掲載画像の検索向け設定
- CNAME：独自ドメイン
- renewal/index.html：旧テストURLからトップページへの誘導

## 運用メモ

住所・電話番号は公開資料で照合済みです。参拝時間は通常7:00〜17:00として掲載しています。由緒の照合と記述判断はHISTORY-SOURCES.mdを参照してください。

山門・境内・地蔵尊・弘法大師像、本堂内陣、御本尊・大日如来の写真を掲載しています。

由緒の文章とすべての写真は、JavaScriptを実行せずにHTMLから読み取れます。本堂・御本尊は、元のPNGと同じ画素を保ったWebPで配信しています。画像を更新するときは、index.html内の画像URL・実寸・構造化データと、sitemap.xml内の画像URLも合わせて更新してください。

正式URLをcanonicalに指定し、寺院・ウェブサイト・ページの構造化データを掲載しています。Google Search Consoleでの所有者確認とサイトマップ送信は、Googleアカウント側で別途行います。これらの設定だけで検索への掲載や順位を保証するものではありません。

サイトはフォームで情報を受信しません。メールアプリ・LINE・Googleマップなど外部サービスを利用します。
